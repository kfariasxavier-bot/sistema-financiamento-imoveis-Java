# Sistema de gerenciamento de álbuns de música (Python)
Meu projeto acadêmico desenvolvido por mim na disciplina de Fundamentos da Programação Orientada a Objetos (ADS - PUCPR)

## O que o sistema faz
- Cadastra e salva financiamentos de imóveis
- Lista todos os Financiamentos
- Calcula e mostra o valor total final de todos os imóveis

## Linguagem
- Java

## Como executar
1. Baixe o repositório
2. Abra a pasta em uma IDE
3. Execute: 'Main.java'

## Comandos
- Por meio de números permite que você adicione os financiamentos e veja quantos foram salvos, seus valores finais e a soma
